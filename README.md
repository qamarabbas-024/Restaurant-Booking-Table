# 🍽️ Restaurant Table Booking System

A console-based Restaurant Table Booking System built in C++.

This project demonstrates:

- Object-Oriented Programming (OOP)
- Modular Architecture
- Smart Table Assignment
- Conflict Detection
- File Handling
- Cross-Platform Support

---

# 📌 Features

- Add Tables
- Create Booking
- Cancel Booking
- Search Booking
- Show Available Tables
- Dashboard System
- Smart Table Assignment
- Conflict Detection
- File Handling
- Input Validation
- Cross Platform Screen Clear

---

# 📚 OOP Concepts Used

- Classes & Objects
- Constructors
- Encapsulation
- Abstraction
- Composition
- Modular Programming
